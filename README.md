# Woo Upsell Products

Displays WooCommerce upsell products as selectable checkboxes and adds selected items alongside the main product.

## Installation

1. Place this directory at `wp-content/plugins/woo-upsell-prods/`.
2. Activate WooCommerce, then activate **Woo Upsell Products**.

## Usage

Assign upsells to the main product and open its product page. Select an upsell before adding the main item to the cart. The plugin also registers `[wup_upsells]`.
